<details>
<summary><b>Cara aktifkan Snake Animation (klik untuk lihat)</b></summary>

1. Buat folder `.github/workflows` di repo profilmu.
2. Buat file `.github/workflows/snake.yml`:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v3
      - uses: Platane/snk@v3
        with:
          github_user_name: YOUR_USERNAME
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Ganti `YOUR_USERNAME` pada workflow.
4. Harus sudah membuat branch `output` di repo profilmu.
5. Push, lalu jalankan workflow sekali dari tab **Actions**.
6. Tunggu ~1 menit sampai animasi ular muncul di README-mu.

</details>
